## 3. 五种方法的实际区别

| 方法 | 几何与渲染路径 | 历史与原图的使用 | 是否持续维护一个全局地图 |
|---|---|---|---|
| WorldWarp 原版 | TTT3R → WorldWarp 原生 GS → 扩散 | 首段用输入图；后续 TTT3R 处理上一段 49 帧，GS 用末尾 5 个连续视图建模 | 否，每段重新拟合 GS |
| 三项目组合 | MapAnything → GaME 静态 GS / 渲染 → WorldWarp | 只用首图拟合一次 GaME；历史进入视频上下文和文本，不更新地图 | 保持一份固定静态场景，但不更新，也不是完整环境重建 |
| F | MapAnything → WorldWarp 原生 GS → 扩散 | 每段用本方法历史重新估几何、拟合 GS；不额外加入原图 | 否 |
| G | MapAnything → 原图约束的原生 GS → 扩散 | 在 F 基础上加入原图，原图权重 2 | 否 |
| H | MapAnything → 点云投影 → 扩散 | 同样保留原图；不用 GS 优化 | 否 |

F/G/H 的几何关键帧是上一段局部 **0/12/24/36/48**；视频上下文是连续末尾 **44–48**，两组选帧不同。G/H 去掉重复的全局第 0 帧，后续来源数为 1/5/6/6/6；F 为 1/5/5/5/5。生成历史不是新增的真实观测，其实际运动也不保证等于请求相机。

F/G 每段原生 GS 优化 500 步，每来源最多 5 万初始高斯点、总上限 35 万；单视图权重为 1，多视图原图权重为 2、历史视图为 1。含平移时使用渲染 alpha 与来源深度一致性掩码（相对阈值 .1）。H 使用逐来源 z-buffer、双线性点投影和加权 RGB 融合。GaME 则在 720×480 拟合一次 500 步加 50 步预热、seed 0，固定场景使用原生 alpha 渲染。

三项目与 F/G/H 都额外用 **首图单独 TTT3R / MapAnything 深度比的中位数**校准一个全局深度尺度；不使用参考视频深度。F/G/H 后续窗口沿用此标量，没有额外校正窗口间尺度漂移。其生成器不加载 TTT3R 模型，但整条评测流程的首图尺度校准阶段确实使用了 TTT3R，不能描述成全流程完全不用 TTT3R。

## 4. 六项指标如何解释

| 指标 | 趋势 | 本地定义及限制 |
|---|---|---|
| PSNR | 越高越好 | RGB [0,1] 全图均方误差转 dB；很敏感于视角和位置不对齐 |
| SSIM | 越高越好 | 11×11 高斯窗、sigma 1.5、总体协方差，RGB 通道平均 |
| LPIPS | 越低越好 | AlexNet、v0.1，衡量感知差异；较清晰不保证几何正确 |
| FID | 越低越好 | pytorch-fid Inception 2048 维；端点仅 5 张图，统计不稳定，仅作诊断 |
| R_dist | 越低越好 | 独立 DUSt3R 重建生成相机后，相对首帧计算与数据集相机的旋转测地距离，单位 rad |
| t_dist | 越低越好 | 两条轨迹各自相对首帧、各自按最大位移半径归一化，再计算平移 L2；不是米，也不是时间误差 |

DUSt3R 使用 512 DPT；第 50 帧端点取索引 0、9、19……49，共 6 视图；第 200 帧取 0、9、19……199，共 21 视图。完整双向配对、MST 初始化、300 步全局优化、cosine 调度、lr .01；不做额外 Procrustes 拟合。真实视频也独立重建作为诊断，其误差不能直接从生成误差中扣掉。

PSNR、SSIM、LPIPS、R_dist、t_dist 对五场景等权平均。FID 是合并端点特征后计算，**不能平均原来“3 场景 + 2 场景”两批的 FID**。退化、模糊、结构错误的生成图也可能使 DUSt3R 位姿估计不可靠。

## 7. 如何理解这组结果

### 7.1 图像保真与感知质量存在取舍

第 50 帧，F/G 的平均 PSNR、SSIM 好于原版，但平均 LPIPS 更差；增加 MapAnything 或原图约束没有带来一致收益。

第 200 帧，原版的平均 SSIM 高于其余四种方法；三项目平均 PSNR 略高于原版，但其余指标仍有取舍。F/G/H 平均 PSNR、SSIM 均低于原版。H 的平均 LPIPS 为 0.7286，低于原版 0.7864，也在 4/5 场景改善；然而 H 的 PSNR、SSIM 在全部 5 个场景均下降。

这些结果与画面中“保留清晰物体，但停留在错误构图”相符。不能把更清晰直接解释为新视角更准确，也不能仅凭模糊画面的部分像素分数较高认定它更好。

### 7.2 平移控制仍然是明显问题

第 200 帧原版平均 t_dist 为 **0.6470**；三项目为 **0.8428**，F 为 **0.7428**，G 为 **0.7170**，H 为 **1.0888**。所有组合的平均值都更差。F/G 虽各有 3 个场景改善，少数较大的退化仍抬高了均值；因此应同时查看均值和场景明细。

### 7.3 旋转均值受到汽车展厅案例的显著影响

原版汽车展厅第 200 帧旋转误差约 **2.6715 rad**，画面已严重退化。F/H 的平均 R_dist 下降各自仅由这一个场景贡献，另外四个场景都变差；G 有两个场景改善，三项目也仅有汽车展厅改善。原版在该场景的 DUSt3R 估计可能不可靠，不能把均值下降说成普遍的镜头跟随提升。

### 7.5 当前能得出的结论边界

本轮是整套管线对照：几何估计器、GS 渲染器、地图更新方式、可见性掩码和各自历史文本同时可能不同，不能把差异全部归因于 GaME、原图锚定或点云。首图尺度校准也不保证后续 MapAnything 窗口始终处于完全一致的尺度。

没有跨场景、跨种子的证据证明某条管线总体最好。当前可作为后续固定协议的本地基线，不能直接对照论文排名，也不能将此前 classroom 纯旋转下的已知区域 PSNR / 时间 MAE 当作本次真实轨迹六项指标。
