> **2026-09-18 核查更正：**这些运行已完成评分，但尚未通过参考视角对齐验收。共用的 TTT3R 控制相机与数据集标定有偏差（第 50 帧焦距高约 10%–47%，温室朝向偏差约 7.57°）；本地基线适配还遗漏上游参考视频入口的内参时间平均。二者不是同一问题，尚未证明仅修正内参平均即可恢复正确生成。本报告保留原视频及分数作为本地配置结果，不据此声称论文基线复现成功或确定几何模块优劣；暂无修正后的 GPU 重跑结果。

## 方法与评测设置

F：滚动历史 GS；G：原图约束 GS；H：原图约束点云。均为 MapAnything + WorldWarp，不使用 GaME。
与之前原版 / 三项目对齐 225 帧、720×480、30 fps（7.5 秒）、5×49 帧 / 后续重叠 5、strength .8、采样 50、CFG 5、seed 32。完整 SE3 轨迹来自同一参考相机，图像 / 相机哈希一致。这是基准适配版，不是旧 classroom .6 纯旋转配置。

首图单独 TTT3R / MapAnything 深度比中位数校准一个全局尺度，后续窗口沿用，窗口尺度漂移未额外修正。F/G 每段拟合原生 GS 500 步，H 不优化 GS。几何关键帧取上一段 0/12/24/36/48，视频上下文取连续末尾 5 帧。G/H 原图权重 2；生成历史不是真实观测。Qwen 跟随各自历史，后续文本可能不同。

## 结果解读

没有一种 F/G/H 组合在这五个场景上全面优于原版。第 200 帧三者平均 PSNR / SSIM 都下降，平移误差都上升；G/H 的平均 LPIPS 下降。H 在 4/5 场景的 LPIPS 改善，但 PSNR、SSIM 在 5/5 场景均下降，不能把外观清晰等同于目标视角正确。

抽帧显示：H 在温室与餐厅更清晰，G 在商铺保留店面细节较好；F 经常出现错误遮挡、雾状纹理，G 在部分其他场景仍严重退化，H 也没有正确保持建筑和汽车展厅的目标视角。

第 200 帧 F/H 的平均旋转误差下降分别仅由汽车展厅这一个场景贡献，其余四个场景均变差；G 有两个场景下降。原版汽车展厅已经严重退化，DUSt3R 位姿估计可能不可靠，均值不能当成普遍运动控制提升。此次同时改变几何估计、渲染和历史更新，自动文本也随各自历史变化，不能单独归因于有无 GaME 或原图锚定。
