## 固定参数与核验

- 同一个场景 `032dee9fb0a8`，在生成前固定；仍按原时间顺序使用 225 帧，没有挑成功帧或改变播放速度。
- 720×480；5 段×49 帧，后续重叠 5；50 步采样，CFG 5，seed 32，strength .8。几何为原生 TTT3R → GS，扩散为 WorldWarp。
- 生成只读取真实首图及自身生成历史；参考视频 RGB 用于估计轨迹，参考序列深度不用于生成。
- 两条新运行均逐张量核验实际微调权重，保持 WorldWarp 原生几何和扩散；诊断钩子仅保存结果。
- [发布权重核验](../../../../Reports/dl3dv_worldwarp_recheck_20260918/official_weight_audit.json)：本地 checkpoint 的 SHA-256 与作者 Hugging Face LFS 文件一致。
- 使用编码前 PNG 计算图像指标；DUSt3R 从生成图独立估相机。严重退化时位姿评分也可能不可靠。t_dist 是归一化空间平移误差，不是时间或米。
- 标定相机诊断的内参和旋转与 GT 一致，平移尺度来自两套相机轨迹的正标量最小二乘拟合。它不是成功复现论文相机协议的证据。
- 本地低分辨率数据、场景划分、帧采样与若干评分细节不保证与论文完全相同。
- [完整指标 JSON](../../../../Reports/dl3dv_worldwarp_recheck_20260918/metrics_comparison.json)；evidence/ 保存配置、相机、评分明细、权重核验及每段几何诊断。原运行还保留生成 PNG 与最终 GS。无逐去噪 latent 或每次 GS 迭代模型。
- 下载整个本报告文件夹可查看本文引用的全部视频、图片和证据；重新运行脚本仍需服务器原数据和模型。

## 实际观察与尚未解决的问题

1. 恢复上游 K 平均后，第 50 帧仍与旧结果接近；第 200 帧墙面和台阶较清楚，但雕像/基座的位置、尺度与 GT 明显不同。生成位姿的 R_dist 从旧值约 0.759 降到 0.262 rad，不代表图像和几何已对齐。
2. 标定相机诊断同样失败：第 200 帧雕像丢失，基座变成近处的大块墙面。第 50/200 帧 PSNR 为 11.175/10.972 dB。输入的旋转和内参已与数据集一致，因此不能把全部问题归因于 TTT3R 控制轨迹。
3. 首段几何渲染就存在缺失/拉伸；后续生成历史被重新建模，几何条件也逐渐偏离真实场景。扩散结果还会改变几何提示中的主体与构图。几何估计、局部坐标/尺度一致性、扩散跟随三者的具体责任仍需进一步受控实验，尚未找到一个经过验证的完整修复。
4. 两条新运行的 225 张 GT PNG、数据集相机和原始 TTT3R 预测均与旧实验一致，见 [输入配对核查](../../../../Reports/dl3dv_worldwarp_recheck_20260918/paired_input_audit.json)。首帧重建三者相同，PSNR 约 43.07 dB，排除了首图读错/转换即造成巨大误差的解释。
5. 这些结果是诚实保留的复现尝试与排错对照，没有只挑成功片段、改变轨迹速度、调整 seed 或用后续真实图片替换生成历史。原版权重正确、流程完整，与输出质量成功是两个不同的验收条件。
